# 완성본 시연 순서와 정리 — 케셰브(등대, 낯선 접속을 가장 먼저 알아보다)

6차 총공세(22단계 이후) 1~7일차 작업의 최종 정리입니다. 13~22단계 자체의 판정·근거는 [STUDENT_REPRODUCTION.md](STUDENT_REPRODUCTION.md)에 이미 있어 여기서는 다루지 않고, 22단계 다음에 자유롭게 다듬은 부분만 적습니다.

## 1. 제공 기능 vs 내가 만든 기능

| 구분 | 기능 | 위치 |
|---|---|---|
| 제공 | 로그인·기기·세션 표시 틀, 업무 앱 판정 틀, 보안 기록·XDR 경보 틀, AI 연결 절차, 패키지 조회 절차, "내 PC 상태" 카드, 전체 페이지 레이아웃·탭 | `public/`, `src/server.mjs` 등(13~22단계에서도 고치지 않음) |
| 내가 만든 것(13~22단계) | 위 틀 안의 실제 표시 로직(상태 구분, 오류 안내, 필터·상세보기 등) | `student/extension.mjs`(13~20단계 부분) |
| 내가 만든 것(6차 총공세, 이번 작업) | 아래 "핵심 기능 3가지" + 레이아웃 보강 | `student/extension.mjs`(추가분), `student/appearance.json`(신규) |

## 2. 핵심 기능 3가지 시연 순서

```powershell
cd "aleph-defense-starter\on-client"
node src/server.mjs --demo
```

브라우저로 `http://127.0.0.1:5189` 접속 후:

1. **탭 제목·배너 확인** — 탭 제목이 "등대, 낯선 접속을 가장 먼저 알아보다 · ZTNA & XDR"로 보이면 `student/appearance.json`이 적용된 것입니다(앱 이름·색·`student-first` 배치).
2. **"보호 현황" 탭 → 아래로 스크롤 → "종합 상태 개요" 카드** — 원형 게이지(양호 비율 %), 양호/주의/취약 배지, "지금 확인할 항목" 목록, "자료별 건수" 타일이 한 카드에 보입니다. 기기·세션·알림·연결 점검 결과만으로 계산한 값입니다.
3. **"내 PC 점검(학생 구현)" 카드 → "내 PC 실측 조회" 버튼 클릭** — 몇 초 뒤 "실측 N/5" 배지, "PC 자원"(CPU·메모리·디스크), "네트워크·보안 설정(이 PC만)"(네트워크·방화벽·Windows 기록) 두 구역이 뜹니다. 버튼을 다시 누르면 "추이 비교"에 직전 값과의 차이가 보입니다.

## 3. 아직 안 되거나 "확인 불가"로 남은 한계

- **AI 연결(17·18단계)**: 네이티브호스트 계정 연결이 `NATIVE_HOST_CONTEXT_CHANGED`로 두 차례 재현 실패했습니다(2026-10-27). 0.2.21 변경 내역에 관련 수정이 있었으나 재시도하지 않았습니다 — 이미 포털에서 17·18단계 모두 "통과" 처리돼 있어 더 손대지 않기로 했습니다. 수료 뒤에는 수업용 AI 자체가 막히는 것이 정상이라는 점도 포털 "AFTER THE COURSE" 안내에 명시돼 있습니다.
- **업무 앱 판정·보안 조치 실제 집행(14·19단계)**: SDP 서버 연결이 없어 "연결 없음"이 기본값입니다. 이는 운영자 측 인증서 발급이 필요한 부분이라 학생 코드로 해결할 수 없습니다.
- **패키지 취약점 실제 조회(20단계)**: `ON_PROJECT_DIRECTORY` 환경변수가 운영자 측 설정이라 이 PC에서는 "조회 준비 미완료"가 정상입니다.
- **"내 PC 점검"의 네트워크·방화벽·Windows 기록**: 관리자 권한 없이 읽을 수 있는 범위만 수집합니다. 관리자 권한이 필요한 항목은 "권한 부족"으로 표시되며, 이는 버그가 아니라 설계입니다.
- **서비스 실제 연결·실제 비용**: 학생 API 허용 목록에 서비스 조회 경로가 없고 서버 쪽 비밀 설정과 담당자 허용이 필요해 구현하지 않았습니다. 화면은 연결 전·확인 불가로만 보입니다.
- **Windows 방화벽·Windows 기록**: Linux에서는 미지원(`실측 3/5`)이며 Windows PC에서만 5/5가 가능합니다. 2026-10-28 Windows 값은 그날의 실측이고 이번에 재현하지 못했습니다.
- **`student/appearance.json`의 아이콘·시작 그림**: 넣지 않았습니다(이미지 자산 파일이 없어 선택 사항으로 남김).

## 4. 실제로 확인한 근거

| 확인 항목 | 방법 | 결과 |
|---|---|---|
| 종합 상태 개요 렌더링 | 브라우저로 직접 클릭·스크롤 확인 | 게이지·배지·목록 정상 표시, 콘솔 오류 없음 |
| 내 PC 점검 실측 | 브라우저에서 "내 PC 실측 조회" 버튼 클릭 | CPU 64~84%, 메모리 13~15GiB/15.8GiB, 디스크, 네트워크 5개·IPv4 5개, 방화벽 3프로필 켜짐, Windows 경고16·오류2건(2026-10-28, 이 PC 실측값) |
| appearance.json 검증 | `curl http://127.0.0.1:<포트>/student/appearance.json` | `state:"applied"`, 체크아웃 직후에도 동일하게 통과 |
| 가로 레이아웃 | 1400px·375px 두 폭에서 스크린샷 비교 | 넓은 화면 2~4열, 모바일 폭 1열로 정상 전환 |
| 낯선 사람 재현(5일차) | `git clone`으로 새 폴더에 받아 문서만으로 재현 | 막힌 지점 못 찾음(`STUDENT_RUNBOOK.md` 8-5절에 기록) |
| 키보드 접근성 | "다시 조회" 클릭 후 `document.activeElement` 확인 | 포커스가 버튼에 유지됨 |
| 값 검증(2026-10-29) | 숫자 없는 `state:"ok"` 응답을 합성 응답으로 시험 | `실측 0/5 · 확인 불가 5개`, `invalid_response` 표시(성공으로 세지 않음). Linux 데모 서버 기준이며 Windows 실측은 다시 하지 않음 |
| 추가 카드(2026-10-29) | 합성 응답으로 시험 | 「서비스 연결·사용량·비용」은 4개 서비스가 모두 연결 전·확인 불가(0원 아님), 「이상 징후 근거」는 관찰 6건과 한계·출처 표시, 펼침 유지, 모바일 폭 가로 스크롤 없음. 포털 필수 조건이 아닌 보강 |
| 제공 파일 미수정 | `git diff --name-only 846bcb5..HEAD` | `public/`·`src/` 변경 없음(`student/`와 문서만 변경) |
| 코드 최종 커밋 | 기능 변경이 담긴 마지막 커밋 | `424bccbba2dcaefbfac13b231f9a7704ea7906a5` (이 문서 갱신 커밋은 그 뒤에 붙으므로, 제출 직전 `git rev-parse HEAD`로 다시 확인) |

확인하지 않은 것(실행하지 않은 것): `npm run package-app` 등 포장 명령은 공식 안내대로 실행하지 않았습니다. 설치형(패키징) 버전에서의 동작은 확인하지 못했습니다.
